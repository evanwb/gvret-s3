Install GVRET S3.

Turn your ESP32-S3 into a native USB CAN interface for SavvyCAN. Flash the latest tested firmware right here.

ESP32-S3-DevKitC-18 MB flashClassic CAN

Connect your adapter

  1. Close SavvyCAN and any serial monitors. Connect the board with a USB data cable.
  2. If GVRET is already running, select Enter bootloader and choose its application port.
  3. Select Install firmware and choose the ROM download port. Its name may change after the restart.
Use a browser with Web Serial, such as desktop Chrome or Edge. Open this installer over HTTPS or on localhost.

About this install

The full flash image includes the bootloader and partition table, so it also works with erased flash.

Enter bootloader sends a 1200-baud request to running GVRET firmware. Other firmware needs its own way to enter download mode.

If the application port does not appear after installation, power-cycle the device.
